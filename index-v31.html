      PREPARACIÓN MÓVIL
      Recursos y acceso de prueba
      
      
      El procesamiento reduce el lado más largo a 2400 px y amplía imágenes pequeñas hasta 3×. El canvas de una captura 6000×4000 se estima en 14.6 MiB RGBA; no incluye la memoria adicional del navegador, Tesseract o la imagen original. Los canvases OCR se liberan después de leer.
      
      
      Probar desde el celular en la misma red local
      1. En la Mac, desde la carpeta del experimento, ejecuta npm run serve:v31:lan.
      2. En Terminal, consulta la IP local con ipconfig getifaddr en0 (si usas otra interfaz, revisa su IP local).
      3. Abre http://IP-DE-LA-MAC:4176/index-v31.html en Safari o Chrome móvil mientras ambos dispositivos estén en una red privada de confianza.
      4. En iPhone Safari, elige la imagen desde Fotos/Archivos. Para terminar, detén el servidor con Ctrl+C.
      La sesión actual no tiene un iPhone o Android para probar. La página no publica la aplicación.
